# Módulo Catálogo

Este módulo gestiona el catálogo de productos, categorías, subcategorías y filtros avanzados.

## Estructura
- `components/`: Componentes visuales reutilizables.
- `services/`: Interfaces y adaptadores para servicios de catálogo.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de catálogo.
- `screens/`: Pantallas principales del catálogo.

## Servicios Esperados
- Listado de productos
- Filtros avanzados
- Buscador inteligente
- Galerías de imágenes y videos

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
