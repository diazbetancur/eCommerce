# Módulo Extras de Competitividad

Este módulo gestiona multilenguaje, multimoneda y API para integraciones futuras.

## Estructura
- `components/`: Componentes visuales de extras.
- `services/`: Interfaces y adaptadores para servicios de extras y API.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de extras.
- `screens/`: Pantallas principales de extras y configuración.

## Servicios Esperados
- Multilenguaje y multimoneda
- API para integraciones
- Cumplimiento normativo

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
