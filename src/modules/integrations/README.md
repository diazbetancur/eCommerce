# Módulo Integraciones Operativas

Este módulo gestiona la integración con ERP, inventario y facturación electrónica.

## Estructura
- `components/`: Componentes visuales de integración.
- `services/`: Interfaces y adaptadores para servicios de integración y stock.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de integración.
- `screens/`: Pantallas principales de gestión operativa.

## Servicios Esperados
- Integración con ERP
- Control de stock en tiempo real
- Facturación electrónica
- Gestión de devoluciones y envíos

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
