# Módulo Personalización y Marketing

Este módulo gestiona recomendaciones, ofertas y marketing automatizado.

## Estructura
- `components/`: Componentes visuales de personalización y marketing.
- `services/`: Interfaces y adaptadores para servicios de recomendaciones y marketing.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de personalización.
- `screens/`: Pantallas principales de ofertas y recomendaciones.

## Servicios Esperados
- Recomendaciones dinámicas
- Ofertas personalizadas
- Email marketing y notificaciones push
- Integración con redes sociales

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
