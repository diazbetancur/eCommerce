# Módulo Atención al Cliente

Este módulo gestiona la atención al cliente, agentes de IA y soporte por Whatsapp.

## Estructura
- `components/`: Componentes visuales de soporte.
- `services/`: Interfaces y adaptadores para servicios de atención al cliente.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de soporte.
- `screens/`: Pantallas principales de atención al cliente.

## Servicios Esperados
- Agente de IA (futuro)
- Botón de Whatsapp
- Seguimiento de pedidos y recomendaciones

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
