# Módulo Lealtad

Este módulo gestiona el sistema de puntos, recompensas y referidos.

## Estructura
- `components/`: Componentes visuales del programa de lealtad.
- `services/`: Interfaces y adaptadores para servicios de puntos y recompensas.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de lealtad.
- `screens/`: Pantallas principales del programa de lealtad.

## Servicios Esperados
- Sistema de puntos
- Recompensas y descuentos
- Programa de referidos
- Integración con perfil de usuario

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
