# Módulo Recarga de Saldo

Este módulo permite la recarga presencial de saldo en la billetera digital.

## Estructura
- `components/`: Componentes visuales para recarga de saldo.
- `services/`: Interfaces y adaptadores para servicios de recarga y gestión de saldo.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de recarga.
- `screens/`: Pantallas principales de recarga y gestión de saldo.

## Servicios Esperados
- Recarga presencial
- Gestión de saldo y historial
- Integración con pagos y billetera

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
