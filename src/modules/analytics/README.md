# Módulo Analítica y Big Data

Este módulo gestiona dashboards, reportes y análisis de datos.

## Estructura
- `components/`: Componentes visuales de analítica.
- `services/`: Interfaces y adaptadores para servicios de analítica y reportes.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de analítica.
- `screens/`: Pantallas principales de dashboards y reportes.

## Servicios Esperados
- Dashboards en tiempo real
- Análisis de comportamiento
- Segmentación y reportes
- Aprendizaje automático (futuro)

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
