# Módulo Cuentas de Usuario

Este módulo gestiona el perfil, historial de compras y favoritos.

## Estructura
- `components/`: Componentes visuales de usuario.
- `services/`: Interfaces y adaptadores para servicios de usuario.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de usuario.
- `screens/`: Pantallas principales de perfil y seguimiento de pedidos.

## Servicios Esperados
- Perfil de usuario
- Historial de compras
- Seguimiento de pedidos
- Listas de deseos y favoritos

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
