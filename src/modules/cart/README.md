# Módulo Carrito

Este módulo gestiona el carrito de compras y el proceso de checkout.

## Estructura
- `components/`: Componentes visuales del carrito.
- `services/`: Interfaces y adaptadores para servicios de carrito y checkout.
- `types/`: Tipos y modelos de datos.
- `hooks/`: Hooks personalizados para lógica de carrito.
- `screens/`: Pantallas principales del carrito y checkout.

## Servicios Esperados
- Carrito dinámico y persistente
- Proceso de compra simplificado
- Integración con pasarelas de pago
- Opciones de pago locales y billeteras

## Integración
Importa el módulo y usa sus componentes y servicios según la configuración global.
